# 연자 동선지도 기능 명세 (route_map_spec.md)

> 대상: `scheduler/admin/speaker-schedule.html` + `js/speaker-schedule.js` (연자별 강의 일정 탭)
> 목표: 연자 카드에서 버튼 하나로 "행사장 지도 + 번호 배지 + 이동 점선 + 일정표" PNG를 만든다.
> 기준 예시: ASLS 2026 추계 · 11/8(일) 유경훈(5건)·국지수(7건) 동선지도 (Claude 수작업본과 같은 결과가 나와야 함)

---

## 1. 데이터 추가

행사마다 지도 1장과 룸 핀 좌표를 저장한다.

```
/adminConferences/<id>/venueMap
  imageUrl   : Firebase Storage URL (지도만 잘라낸 이미지 권장 — 휴대폰 상단바·헤더 제외)
  width, height : 원본 픽셀 크기
  pins       : { <roomId>: { x: 0~1, y: 0~1 } }    ← 비율 좌표 (이미지 크기 바뀌어도 유지)
  extraPins  : { <key>: { label, x, y } }           ← 등록데스크·VIP 라운지 등 참고 위치(선택)
  updatedAt, updatedBy
```

- 핀은 **roomId 기준**으로 저장한다. 룸 이름("F Room", "오픈렉처B")은 표기가 흔들리므로 매칭 키로 쓰지 않는다.
- 날짜별로 룸이 따로 생성되는 구조라면(토 F Room ≠ 일 F Room), 같은 이름 룸은 **"같은 장소" 그룹**으로 묶어 핀 하나를 공유하게 한다: `pins`의 키를 `placeKey`(정규화한 룸 이름: 공백·대소문자·"Room/룸" 제거)로 두고, roomId→placeKey 매핑으로 찾는다.

## 2. 지도 설정 화면 (관리자, 행사당 1회)

연자별 강의 일정 탭 상단 바에 `🗺 동선지도 설정` 버튼을 추가한다.

1. 지도 이미지 업로드 → Storage `venueMaps/<confId>.png`
2. 이 행사의 룸 목록(placeKey 기준 중복 제거)을 왼쪽에 표시한다. 룸을 고르고 지도를 탭하면 핀이 찍힌다. 다시 탭하면 위치를 옮긴다.
3. 핀이 없는 룸은 빨간 표시를 한다. 저장할 때 "핀 미지정 룸 N개"를 경고한다(저장은 허용).
4. 오픈렉처처럼 지도에 원형으로 표시된 장소도 일반 룸과 똑같이 핀을 찍는다.

## 3. 연자 카드 버튼

기존 `복사 / 메일 / 카톡` 버튼 옆에 `🗺 동선지도`를 추가한다.

- 날짜 선택: 상단 날짜 필터(`FILTER_DATE`)가 있으면 그 날짜를 쓴다. 없으면 **오늘이 행사 기간 안일 때는 오늘**, 아니면 그 연자의 첫 일정 날짜를 쓴다.
- 대상 항목: 그 날짜의 `kind: 'lec'`(강의·패널)과 `kind: 'mod'`(좌장)를 넣는다.
  - `unplaced`(미배치)는 제외한다.
  - `special`(특별행사)은 장소 핀이 없으므로 **일정표에만** 넣고 지도에는 표시하지 않는다.
- `venueMap`이 없는 행사에서는 버튼을 비활성화하고 툴팁 "동선지도 설정에서 지도를 먼저 올려주세요"를 띄운다.

## 4. 그리기 규칙 (Canvas)

### 4-1. 번호와 배지
- 시간순으로 1부터 번호를 매긴다(좌장 포함).
- **같은 장소를 여러 번 쓰면 배지 하나로 합친다**: "5·6", "1·5". 단, 완료/예정이 섞이면 둘로 나눈다(완료 회색 "1", 예정 주황 "5·6").
- 배지는 핀 중심에서 띄워서 놓는다. 룸 블록을 가리지 않게 한다. 후보 오프셋 8방향(상·우상·우·우하·하·좌하·좌·좌상, 거리 ≈ 이미지 폭의 5%)을 차례로 시도한다. 다른 배지나 다른 핀과 겹치지 않는 첫 자리를 쓴다.
- 배지 모양: 둥근 알약, 흰 테두리, 흰 굵은 숫자.

### 4-2. 완료/예정 색
- 기준 시각: 생성 시점의 현재 시각. 선택한 날짜가 오늘일 때만 적용한다(과거 날짜는 전부 완료, 미래 날짜는 전부 예정).
- 종료시각이 이미 지났으면 **완료**(회색 `#96968F`), 아니면 **예정**(주황 `#D85A30`).
- 일정표의 완료 행은 글자를 회색으로 쓰고 오른쪽에 "완료"를 붙인다. 마지막 예정 항목에는 "마지막"을 붙인다.

### 4-3. 이동 점선
- **예정 구간만** 잇는다. 마지막 완료 장소(현재 위치로 간주) → 다음 예정 → … → 마지막.
- 같은 장소 연속(예: A룸 12:45 → A룸 13:27)은 선을 긋지 않는다.
- 주황 점선, 선 굵기는 이미지 폭의 0.5%, 점선 간격은 대략 18px:18px이다. 직선으로 긋고, 경로 계산은 하지 않는다.

### 4-4. 일정표 글상자
- 지도 아래에 캔버스를 늘려서 붙인다. 지도 위에 덮지 않는다.
- 제목: `{연자명} · {M/D(요일)} 동선`
- 행: `[번호원] 시간  장소  제목(짧게)  [완료/마지막]`
  - 좌장 행은 제목 앞에 `좌장 · `을 붙인다.
  - 제목이 칸을 넘으면 `…`로 자른다(한 줄 유지). 강의 제목 원문이 길어서 짧은 제목 필드가 따로 있으면 그것을 우선한다.
- 배경 `#FDF7F2`, 테두리 주황, 모서리 둥글게.
- 폰트: Noto Sans KR (이미 로드됨). Canvas에 그리기 전에 `document.fonts.ready`를 기다린다.

### 4-5. 경고 표시 (일정표 아래 한 줄, 해당할 때만)
- **이동 빠듯**: 서로 다른 장소 사이 간격이 `SPEAKER_TRAVEL_MIN`(10분) 이하면 그 구간 번호를 빨간색으로 하고 "④→⑤ 이동 10분 이하"를 쓴다.
- **겹침**: 기존 `conflict` 플래그가 있는 항목에는 행 끝에 "겹침"을 쓴다.
- **핀 없음**: 핀이 없는 장소는 지도에서 빠졌다고 표시한다. 예: "※ I룸 지도 위치 미지정".

## 5. 출력

모달에서 미리보기를 보여주고, 버튼 3개를 둔다.
- `PNG 저장`: 파일명 `ASLS_{MMDD}_{연자명}_동선.png`
- `공유`: Web Share API (모바일 공유 시트 → 카톡·문자). 지원하지 않는 환경에서는 숨긴다.
- `다른 날짜`: 그 연자가 일정을 가진 날짜 칩 목록

해상도는 원본 지도 폭을 그대로 쓴다(약 1200px). 모바일 갤러리에서 확대해도 글자가 깨지지 않게 한다.

## 6. 하지 말 것
- 지도 원본 위에 일정 글자를 겹쳐 쓰지 않는다. 글은 아래 표에만 쓰고, 지도 위에는 배지와 점선만 그린다.
- 다른 연자 일정을 한 장에 섞지 않는다(1인 1장).
- 자동 발송은 하지 않는다. 연자에게 보내는 것은 관리자가 공유 버튼으로 직접 한다(개인 일정 정보).

## 8. 구현 순서 제안
1. `venueMap` 데이터와 설정 화면(업로드·핀 찍기) — 이것만 있어도 수동 확인 가능
2. Canvas 렌더러 `buildRouteMap(person, date, now)` → `HTMLCanvasElement` (순수 함수, 테스트하기 쉽게)
3. 연자 카드 버튼과 미리보기 모달
4. 경고 표시, 공유, 다른 날짜 전환
